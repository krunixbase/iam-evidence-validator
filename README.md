# IAM Evidence Validator

Audit-ready validator for Identity and Access Management (IAM) evidence.
Designed for SOC 2, ISO 27001, and internal security reviews.

## Deliverables
- IAM control mapping (controls.json)
- CLI validator (validate.py)
- Branded HTML audit report (report.html)

## Scope
- User access reviews
- Role and permission mapping
- Joiner / mover / leaver evidence
- Privileged access controls
